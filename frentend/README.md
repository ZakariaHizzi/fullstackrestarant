# NEON BISTRO — The Future of Flavor

A futuristic, cyberpunk-themed restaurant website built with **React 19**, **Vite 8**, **Tailwind CSS 3**, and **Framer Motion**.

## Tech Stack

- **React 19** with hooks-based architecture
- **Vite 8** for fast dev server and builds
- **Tailwind CSS 3** with a custom dark color scheme and typography scale
- **Framer Motion** for scroll and hover animations
- **React Router DOM v7** for hash-based anchor navigation
- **Oxlint** for linting

## Features

- **Hero Section** — Full-screen intro with animated headline and CTA
- **Featured Dishes** — Grid spotlighting signature menu items with dynamic layout
- **Menu Section** — Expandable item cards showing price, tags, and descriptions
- **Dish Details** — Modal-style overlay with full descriptions, ingredients, ratings, and badges
- **Reservations** — Booking form with date, time, party size, and special requests
- **Reservation Confirmation** — Post-booking success view with summary
- **Contact Section** — Location, hours, phone, email, and social links

## Design

Dark-mode-first aesthetic with:
- Neon orange (`#ff5f00`) primary accents on a deep black background (`#111317`)
- Glow effects on headings and interactive elements
- Three distinct fonts: Sora (headlines), Inter (body), Space Grotesk (labels)
- Smooth scroll between sections via hash links

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

Lint:

```bash
npm run lint
```
